# Presets

Preset files here are exported manually from REAPER.

1 - Go to the track's FX menu.
2 - Configure it to you liking and if the plugin requires a file at a certain path select an example one preferably
2 - Click the '+' icon
3 - Save it as a preset
4 - Export the preset bank as a ".rpl"
5 - Open the ".rpl" and please delete any non relevant or default presets
